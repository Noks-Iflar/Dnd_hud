# HUD Хвора — модуль для Foundry VTT

Боевой HUD в стиле тёмного фэнтези для кампании «Хвор». Автор и ГМ — Нокс. Код пишет Claude, Нокс тестирует в Foundry и решает, как всё должно выглядеть и работать.

## Как работать с Ноксом

- Отвечать по-русски.
- Нокс учится программировать. После каждого изменения коротко объясняй, что поменялось и почему, простыми словами, без лекций.
- Меняй только то, о чём просили. Если видишь проблему рядом, скажи о ней, но не исправляй молча.
- Запустить Foundry ты не можешь. Проверка: Нокс жмёт F5 в Foundry и присылает ошибки из консоли (F12 → Console). Перед этим сам проверь синтаксис (`node --check scripts/main.js`).
- Изменения, которые ломают совместимость или удаляют файлы, сначала согласуй.

## Окружение

- Foundry VTT **V14** (14.370), система **D&D 5e 6.1.1**, правила 2024 года, русская локализация (модули Russian Translation и Babele).
- **Midi-QOL 14.7.1 включён** (поддерживает dnd5e 6.1.x; требует DAE ≥ 14.6.10, DAE обновлён). Автоматизацию базовых действий строить с учётом Midi: не дублировать то, что Midi делает сам (уклонение, помощь, преимущество/помеха через флаги `flags.midi-qol.*`). Встроенные режимы броска dnd5e (`abilities.*.check.roll.mode` и т. п., 1 — преимущество, −1 — помеха) тоже доступны.
- Важные соседние модули: Midi-QOL, DAE, Automated Conditions 5e, Simple Cover 5e, Sequencer, JB2A (Patreon), Automated Animations, Token Magic FX, Tidy 5e Sheets, DFreds Convenient Effects, Item Piles, Glyph.
- Кампания: 3 игрока 9-го уровня (Дайдэн — дроу, бард, ставший колдуном; Муарен — плут; Мерик — воин). У ГМа много NPC, в том числе существа с Хвором (магической заразой мира).

## Принципы HUD (утверждены Ноксом)

1. Работает на **любом токене**: выделен один токен — показываем его. Ничего не выделено: игроку — его персонажа (`game.user.character`), ГМу — HUD скрыт.
2. Занимает только **нижнюю полосу экрана** и не лезет в центр сцены.
3. **Ничего не настраивается руками**: панель способностей собирается из листа персонажа сама, пустых ячеек нет.
4. Подробности показываются **по запросу**: компактная подсказка при наведении, полное описание по Shift.
5. Атмосфера тёмного фэнтези: Diablo (сфера ПЗ), Divinity: Original Sin 2 (ромбы, рамки), оформление под Хвор.

Что брали у других HUD: у Argon — левый блок (портрет, ПЗ, КБ, СЛ, отдых) и группировку действий по типу; у BG3 Inspired HUD — компактность, переключатель преимущество/помеха, наборы оружия; у Beaver's HUD — сферы, счётчики, полосу инициативы. Что не нравилось: у Argon огромные плитки и подсказки на пол-экрана; у BG3 — много пустых ячеек, непонятно, что в них; Beaver's работал только для персонажей игроков.

## Раскладка (по макету)

- **Слева:** сфера ПЗ (кровь, временные ПЗ значком), портрет в рамке, над портретом кнопки «инициатива» и «навыки», характеристики (КБ в щите, СЛ заклинаний или пассивная внимательность, инициатива, скорость с сегментной полоской остатка движения), переключатель «преим. / обычн. / помеха», наборы оружия I/II, короткий и долгий отдых. Над панелью — ряд эффектов.
- **В центре:** плитки способностей ~56 px (иконка предмета + короткая подпись), сгруппированные по типу действия: действие, бонусное, реакция, предметы; у NPC ещё легендарные. Под каждой группой подпись с ромбом экономии действий (гаснет, когда потрачено). Мини-сетка базовых действий: рывок, отход, уклонение, помощь, засада, подготовка. Сверху вкладки-фильтры (все / атаки / заклинания / умения / предметы) и ячейки заклинаний ромбами (горит — есть, пусто — потрачено), ячейки договора колдуна отдельно. Над панелью — ромб-гребень.
- **Справа:** инвентарь, лист, книга заклинаний, журнал (у ГМа для NPC: добыча, статблок, цели, эффекты) и кнопка «Завершить ход».
- **Сверху экрана:** полоса инициативы — прямоугольные портреты с тонкой полоской ПЗ, текущий ход крупнее с красным свечением.
- **Эффекты:** концентрация — плашка с названием, раундами и крестиком «прервать»; остальные эффекты — иконки 30 px с числом раундов и крестиком «снять». Игрок снимает эффекты только своего персонажа, ГМ — любые.
- **Режим ГМа для NPC:** вместо ячеек — легендарные действия и сопротивление легендарного существа, перезарядка «5–6» (потраченная способность бледнеет), переключатель «открытые / скрытые броски».

## Как устроен код

- `findActor()` решает, чей HUD показывать. `KhvorHud._prepareContext()` собирает данные для шаблона.
- Кнопки в шаблоне — `data-action="..."`, обработчики в `DEFAULT_OPTIONS.actions` (статические приватные методы, `this` — экземпляр HUD).
- Перерисовка — `hud.render({ force: true })` через `foundry.utils.debounce` на хуках: canvasReady, controlToken, updateToken, updateActor, create/update/deleteItem, create/update/deleteActiveEffect.
- `_onRender` плавно анимирует уровень крови (`clip-path: inset(N% 0 0 0)`).
- Окно без рамки: `window: { frame: false, positioned: false }`; позиция задаётся в CSS (`#khvor-hud { position: fixed; bottom; left: 50%; width: max-content }`).
- Сброс стилей кнопок Foundry — через `:where(#khvor-hud) button { all: unset }`: `:where` обнуляет вес селектора, иначе он перебивает классы `.kh-*`.
- Настройки: `rollMode` (client, скрытая), `hideHotbar` (прятать стандартную панель макросов, пока HUD открыт).
- Данные dnd5e: ПЗ `system.attributes.hp` (`effectiveMax ?? max`), КБ `attributes.ac.value` (в 6.x исходные формулы лежат в `ac.calcs`, но итог — в `ac.value`), инициатива `attributes.init.total`, скорость `attributes.movement.walk` и `.units`, СЛ `attributes.spell.dc` при заданном `attributes.spellcasting`, пассивная внимательность `skills.prc.passive`. Хвор: статус `khvor` или эффект со словом «Хвор» в названии.
- Использование способностей — через активности dnd5e (`activity.use()` / `item.use()`): Midi-QOL подхватывает это сам.

## Готово (v0.1.x)

Левый блок целиком: сфера ПЗ с Хвором и временными ПЗ, портрет (клик — лист), бросок инициативы, КБ, СЛ / пассивная внимательность, инициатива, скорость, переключатель режима броска (пока только запоминает выбор), отдых (только у персонажей). Нокс проверил в Foundry — работает.

Центральный блок, шаг 1.1 (Нокс проверил): плитки способностей по группам «действие / бонусное / реакция / легендарные / предметы», без нажатия. `collectAbilities()`: одна плитка — одна активность; пропускаются копии заклинаний с флагом `dnd5e.cachedFor` (их картинка идёт на плитку активности «cast»), пассивные черты без активностей, ненадетое оружие и снаряжение, активации «особое» и по времени.

Шаг 1.2 (Нокс проверил): плитка — кнопка `data-action="useAbility"`, клик вызывает `activity.use({ event })`; чужого актёра использовать нельзя. Режим броска в бросок пока не передаётся.

Шаг 1.3 для NPC (Нокс проверил): `tileState()` — значок зарядов «2/3» (сначала `activity.uses`, потом `item.system.uses`; остаток = max − spent), перезарядка «5–6» (`uses.recovery` с `period: "recharge"`, порог в `formula`), «×N» у расходников, цена легендарного действия ромбами (`activation.value`); плитка бледнеет (`is-spent`), если зарядов 0 или легендарных действий (`resources.legact`: max − spent) меньше цены. Ячейки заклинаний и договора — ниже.

Базовые действия (Нокс проверил): `BASIC_ACTIONS` — мини-сетка 3 × 2, теперь в левом блоке (см. ниже). Клик — карточка в чат с кратким правилом 2024; «Уклонение» переключает состояние `dodging`, только если оно есть в `CONFIG.statusEffects`; «Засада» бросает Скрытность (`actor.rollSkill({ skill: "ste", event })`).

Вкладки, страницы, две строки (Нокс проверил): `paginate()` — вкладки «Все / Атаки / Заклинания / Умения / Предметы» (`tileCategory()`; вкладка без плиток скрыта), страница = строки × `pageColumns()` плиток подряд по группам (столбцов 5–12, считаются от свободной ширины, см. ниже), группы без плиток на странице скрыты. Вкладка и страница живут в `hud.panel` и сбрасываются при смене актёра; одна/две строки — скрытая клиентская настройка `tallPanel`. В двух строках у группы `--cols` = половина плиток, порядок слева направо.

Подсказка способности, шаг 2 (ждёт проверки Нокса): свой блок `.kh-tip` над панелью, не `data-tooltip` Foundry. `abilityTip()` собирает имя, «вид · тип действия · дальность» и строку «Атака +8 · Испытание Ловкость СЛ 21 · Урон 17d6 огонь» из `activity.labels` (`toHit`, `damages`, `range`) и `save.dc.value`; у «cast» берётся активность сотворяемого заклинания. Зажатый Shift показывает описание через `TextEditor.enrichHTML` (у «cast» — описание заклинания).

Листы игроков, конец шага 1 (ждёт проверки Нокса):
- Заклинания — только с `system.prepared` ≥ 1 (1 — подготовлено, 2 — всегда). Значок круга «III» (у договора фиолетовый); плитка бледнеет, если нет ячейки этого круга или выше (`hasSlot()`; заклинания договора — только ячейкой договора).
- `forward` (бесплатное сотворение, тратит заряды предмета) — отдельная плитка «Тьма (своб.)» с зарядами; подсказка берёт активность, на которую он ссылается (`activity.activity.id`). Если у актёра нет ячеек вовсе, обычная плитка заклинания за ячейку не показывается.
- Заряды предмета у заклинания показываются только на активности, которая их тратит (`consumption.targets` с `itemUses`). У одноразового расходника вместо «1/1» только «×N».
- `groupOf()`: новая группа «Особые» — активация «особое» с зарядами (Порыв к действию); легендарное сопротивление туда не попадает. Инструменты в панель не попадают.
- `displayName()`: несколько активностей предмета в одной группе подписываются именами активностей («Хитроумное действие» → Рывок / Отступление / Засада).
- `spellSlots()`: над панелью ряды ромбов по кругам (`spells.spellN.value/max`) и «Договор» (`spells.pact`), картинки `gem-slot` / `gem-pact` / `gem-socket-empty`.

Новый левый блок и место на экране (Нокс проверил):
- Портрет прямоугольный 145×194 в рамке `initiative-frame` (окно x 16–222, y 46–274), под рамкой тёмная подложка; имя под портретом. Сфера ХП 132 px справа, заходит на края портрета и панели.
- Звезда в левом верхнем углу портрета — героическое вдохновение (`system.attributes.inspiration`, клик переключает, только персонажи). Концентрация (`actor.statuses` с `concentrating`) — фиолетовое свечение портрета и значок `status-concentration` справа вверху.
- При 0 ПЗ у персонажа в сфере вместо цифр спасброски от смерти (`attributes.death.success/failure`, по 3 ромба), клик — `actor.rollDeathSave({ event })`.
- Панель в две строки: сверху инициатива, навыки, «Преим./Обычн./Помеха», иконки короткого и долгого отдыха; снизу щит КБ, столбик «СЛ закл.» / «иниц.» (у не-заклинателей пассивная внимательность), скорость с полоской движения, базовые действия 3 × 2 по 28 px.
- Полоска движения (`movement_()`): деление = 5 фт, не больше 12. В начатом бою у токена-участника пройденное = `canvas.grid.measurePath(token.movementHistory).distance`, показ «15/30 фт»; вне боя просто скорость. Не проверено: сбрасывает ли Foundry `movementHistory` в начале хода. Рывок пока не удваивает скорость (шаг 3). Перерисовка также на `updateCombat` и `deleteCombat`.
- HUD прижат к левому краю (`left: 12px`); список игроков Foundry (`#players`) на это время прячется (клиентская настройка `hidePlayers`, по умолчанию да). Справа граница — левый край `#sidebar` (`freeAreaRight()`), пересчёт на `collapseSidebar` и `resize`. Столбцов на странице `pageColumns()` = (граница − 12 − 620 левый блок − 220 правый блок 200 − 160 рамки) / 53, от 5 до 12. Полоса вкладок не растягивает панель (`width: 0; min-width: 100%`), ячейки и листалка переносятся на вторую строку.

Правки после проверки (Нокс проверил): портрет +15% (145×194); рамка сферы тоньше — стекло 78% вместо 66.8%, внутренняя часть `orb-frame` срезана маской `radial-gradient(… transparent 0 77%, #000 78%)`; при концентрации по рамке портрета бежит дуга (`::after` с `conic-gradient` от `--kh-angle`, `@property` + анимация 2.4 с, без анимации при `prefers-reduced-motion`); плитки 45 px (ширина 50), подписи и значки 10 px, вкладки мельче.

Раскладка v2 (ждёт проверки Нокса; правый блок с кнопками «Инвентарь / Лист / …» Нокс отверг — лист открывается кликом по портрету):
- Слева направо: портрет (это `actor.img` — портрет актёра, не картинка токена) → сфера ХП → узкая левая панель → средняя панель способностей → правый блок.
- Левая панель в три столбца (261×108): щит КБ | скорость с полоской, «СЛ закл.» или «пасс. вним.», «иниц.» | кнопки 2 × 2 (инициатива, навыки, короткий и долгий отдых). Ширина левого блока целиком ≈ 485 px (`LEFT_BLOCK_WIDTH`).
- Правый блок `.kh-right` в рамке: «Преим. / Обычн. / Помеха», базовые действия 3 × 2 (36 px), «Завершить ход» — только в бою (`endTurnState()`, активна в свой ход, `combat.nextTurn()`).
- Средняя панель шире: `LEFT_BLOCK_WIDTH` 485, `RIGHT_RESERVE` 210 → на 1920 px с открытым чатом 12 плиток в строке.
- Фильтр по типу действия без новой строки: подпись группы («◆ Бонусное») — кнопка `setGroup`. Клик оставляет только эту группу, остальные сворачиваются в приглушённые подписи (`stub`), повторный клик — все группы. Сочетается с вкладками (например, «Заклинания» + «Бонусное»).
